# SC-13 Cryptographic Protection

| Family | Baseline | Responsibility | Status |
|---|---|---|---|
| System and Communications Protection | Moderate | Shared | Implemented for the platform; application and OS layers documented in `docs/fips-140.md` |

## Control summary

Determine the cryptographic uses and the type of cryptography required for
each use, and implement it in accordance with applicable laws, policies and
standards.

## FedRAMP Rev 5 parameters

- FIPS 140-2 or 140-3 validated cryptographic modules for all cryptography protecting federal information (encryption at rest, in transit, hashing, digital signatures, key management).

## Implementation

| Cryptographic use | Type | Module | Evidence of validation |
|---|---|---|---|
| Key management | AES-256 symmetric keys in HSMs | AWS KMS, FIPS 140-3 Level 3 | AWS FedRAMP package |
| Encryption at rest | Envelope encryption with KMS data keys (S3, EBS, Aurora, Secrets Manager, CloudWatch Logs, SNS, SQS) | AWS services within the FedRAMP boundary | AWS FedRAMP package; `docs/resource-inventory.md` |
| API transport | TLS 1.2+ to `*-fips` endpoints | AWS endpoint TLS stacks (FIPS validated) | `providers.tf` (`use_fips_endpoint`), Lambda `AWS_USE_FIPS_ENDPOINT`, VPC endpoints `kms-fips`, `secretsmanager-fips`, `sts-fips`, `logs-fips` |
| Edge transport | TLS to CloudFront | CloudFront TLS (FIPS policy `TLSv1.2_2021` with a custom certificate) | `docs/fips-140.md`; distribution config |
| Database transport | TLS enforced by Aurora | Aurora TLS stack | parameter `require_secure_transport` |
| Audit integrity | SHA-256 digests signed with RSA | CloudTrail | `cloudtrail validate-logs` |
| Secrets | Secrets Manager with KMS | AWS | RDS-managed secret attributes |

**What this means in practice.** Terraform itself, the containment Lambda,
and any workload inside the VPC talk to AWS only through FIPS endpoints;
the data never touches a non-validated TLS stack between the customer and
AWS. All stored data is encrypted by KMS-backed envelope encryption. Hashing
and signing of audit records happen inside CloudTrail.

**Validated versus compliant.** Only CMVP-validated modules count. "Uses
AES" is not evidence; a certificate number is. See `docs/fips-140.md` for the
distinction, the regional availability of FIPS endpoints (the reason the lab
runs in us-east-1), and the operating system and library requirements for
hosts and containers (Bottlerocket FIPS, Amazon Linux 2023 FIPS mode, OpenSSL
FIPS provider, language runtimes).
