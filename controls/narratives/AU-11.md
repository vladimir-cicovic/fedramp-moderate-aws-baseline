# AU-11 Audit Record Retention

| Family | Baseline | Responsibility | Status |
|---|---|---|---|
| Audit and Accountability | Moderate | Customer | Implemented (lab values; production values noted) |

## Control summary

Retain audit records for a defined period to support after-the-fact
investigations and to meet regulatory and organizational retention
requirements.

## FedRAMP Rev 5 parameters

- Retain audit records for at least one year; keep at least 90 days readily available online.
- Federal guidance OMB M-21-31 extends this for agencies: 12 months active storage plus 18 months cold storage (30 months total). Treat it as the production target.

## Implementation

| Store | Online (hot) | Cold | Expiry | Notes |
|---|---|---|---|---|
| CloudTrail bucket | 90 days S3 Standard | Glacier Instant Retrieval after 90 days | 400 days (lab) | Object Lock prevents earlier deletion; versioning keeps noncurrent versions 30 days |
| Config bucket | 90 days | Glacier IR | 400 days | |
| S3 access logs bucket | 90 days | Glacier IR | 400 days | |
| CloudWatch Logs (CloudTrail, flow, WAF, CloudFront, Aurora, Lambda) | 400 days | n/a | 400 days | KMS encrypted |
| AWS Config configuration history | 7 years (2557 days) | n/a | | retention configuration resource |
| Security Hub findings | 90 days after last update (service default) | | | exported weekly by the evidence workflow for long-term retention |
| GuardDuty findings | 90 days (service default) | | | archived through Security Hub export |

Lifecycle rules are Terraform variables (`log_expiration_days`,
`cloudwatch_log_retention_days`), so moving to the M-21-31 schedule is a
values change: expiry 913 days with Glacier after 365, CloudWatch Logs 400
days plus S3 export, or forward everything to the SIEM with its own retention.

## Evidence

| Artifact | Collection |
|---|---|
| Bucket lifecycle rules | `aws s3api get-bucket-lifecycle-configuration --bucket <bucket>` |
| Log group retention | `aws logs describe-log-groups --query 'logGroups[].{name:logGroupName,days:retentionInDays}'` |
| Config retention | `aws configservice describe-retention-configurations` |
| Object Lock default retention | `aws s3api get-object-lock-configuration` |

## Terraform

- `modules/logging/s3.tf` (lifecycle rules, Object Lock)
- `modules/logging/config.tf` (`aws_config_retention_configuration`)
- every `aws_cloudwatch_log_group` resource (`retention_in_days`)

## Gaps and POA&M

- Lab retention (400 days) satisfies the one-year minimum but not M-21-31; adjust variables for production.
- Security Hub and GuardDuty native retention is 90 days; the weekly export (Day 5) is the long-term record and must be in place before the assessment.
